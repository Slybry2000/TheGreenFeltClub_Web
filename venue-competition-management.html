INDEX / 03   HOW IT WORKS — ORGANISERS

Four steps.
That's the flow.

01

Create the competition

Set a title, time window, game type, format (1v1 or 2v2), and scoring method. A unique join code is generated automatically.

02

Configure the rules

Live tracking or winner-only. Race-to or best-of. Lock house rules like scratch-on-8 or push-out so every game is played the same way.

03

Activate & share

Move from draft to active. Share the join code on a printed sheet, in the group chat, or as a QR on the bar TV.

04

Watch it run

Games auto-score. Standings update live. Turn on the TV display. When the time window closes, final standings lock.

INDEX / 05   GAME TYPES & FORMATS

Two games.
Every rule.

  1. 01

    8-Ball

    1v1 or 2v2. Live tracking with full shot recording, or winner-only for speed. Lock eight-on-break, scratch-on-8, wrong-pocket-8, three-foul loss, confirmation shots, and more.

  2. 02

    9-Ball

    1v1 format. Configure lowest-ball-first, combo/carom shots, 9-on-break, push-out rules, winner-breaks, and three-foul loss. Live tracking or winner-only.

  3. 03

    Match length

    Single game, race-to N, or best-of N (odd numbers). Set once per competition. Every match follows the same format.

  4. 04

    Tracking mode

    Live: shot-by-shot recording with rule enforcement. Winner-only: just log who won. Faster for casual nights, deeper for serious ones.

  5. 05

    2v2 teams (8-ball)

    Players pick a teammate when joining. Team invites last 72 hours. Both teammates share the same record.

INDEX / 06   SCORING SYSTEMS

Pick the method
that fits the night.

The organiser sets the scoring system when creating the competition. Three options. Each one tuned for a different shape of night.

01 — WIN POINTS

3 points per win

Simple and immediate. Play more, score more. Best for short nights with a clear points leader.

02 — WIN RATE

Win percentage with floor

Rewards consistency over volume. Players must hit a minimum game threshold before they appear on the board. No one-game wonders.

03 — PERFORMANCE INDEX

Win rate weighted by games

Balances skill and commitment. Score accelerates with each game and plateaus around 20+. Ideal for longer competitions where sample size should matter.

INDEX / 08   GAME ELIGIBILITY

Every game,
validated.

The system checks every game before counting it toward the leaderboard. No manual review required.

  1. 01

    Tagged games only

    When a player starts a game from the competition screen, it is automatically tagged. Only tagged games count. Players can switch to casual mode any time to play side games that do not affect the leaderboard.

  2. 02

    Automatic validation

    The system checks that game type, format, tracking mode, match length, and rule settings all match the competition config. If anything is off, the game is not counted. Organisers do not need to review games manually.

INDEX / 10   COMMON QUESTIONS

Short answers,
fast.

Do venues need approval to run competitions?

Yes. Venue organiser access is granted after a request. It is not open self-service. This keeps the system reliable and prevents misuse of venue-level features.

Is this only for big tournaments?

No. It is built for recurring weekly pool nights and informal competitions where 6 to 30 players want structured scoring and a visible leaderboard without spreadsheet admin.

How do players join a competition?

They open the app and enter the join code (or scan a QR). The app checks them in at the venue and marks them as competing. For 2v2 events, they also pick a teammate.

Can players play casual games during a competition?

Yes. Players can switch to casual mode at any time. Casual games will not be tagged and will not affect the competition leaderboard. They can switch back without leaving the competition.

What happens if a game does not match the competition rules?

The system validates game type, format, tracking mode, match length, and individual rule settings. If anything does not match, the game is not counted toward the leaderboard.

Does the venue TV display need a login?

No. The display URL is public. Just open it in a browser on any screen. The leaderboard updates in real time without authentication.

Which scoring method should I choose?

Win Points for short, fast nights. Win Rate for skill-focused events with enough games. Performance Index for longer competitions where both consistency and volume should count.

Can I run multiple competitions at the same venue?

Yes. Create separate competitions in the Venue Console. Players join whichever ones they want. The TV display can rotate between active competitions automatically.
